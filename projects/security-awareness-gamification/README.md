# Gamified Human Risk Management Framework

## Executive Overview
This project presents an innovative security awareness framework designed from a pedagogical perspective. Traditional security training often relies on passive video completion which fails to change long term behavior. By combining instructional design principles with technical risk governance, this framework transforms employees into active security defenders.

The core campaign utilizes a sixty second narrative script called The Phishing Snowflake Effect. It demonstrates how a single interaction with an artificial intelligence driven phishing attempt can escalate into an enterprise wide security incident.

## Strategic GRC Alignment
This framework bridges the gap between organizational security policies and human behavior:

* Governance: Establishes a proactive security culture by converting policy requirements into engaging micro learning paths, viral internal campaigns, and high status recognition.
* Risk Management: Directly mitigates human risk by tracking click reduction rates and increasing threat reporting velocity to halt social engineering attacks early.
* Compliance: Generates automated timestamped evidence logs mapped directly to NIST CSF 2.0 (PR.AT-01, GV.OC-01) and ISO 27001 (A.7.2.2) controls for seamless audit readiness.

## Core Objectives
* Reduce simulated phishing click rates to under three percent across all departments
* Increase active phishing reporting velocity within fifteen minutes of detection
* Align human behavior metrics directly with recognized security compliance standards

## Key Innovation Highlights
* Framework mapped digital micro credentials for professional development
* Customizable dynamic avatars that evolve visually as security badges are earned
* Internal social amplification features including peer challenges and corporate hashtag trends
* Department level gamification featuring high value operational rewards and status recognition
* Automated audit evidence generation for ISO 27001 and NIST CSF 2.0 controls
